Put notice attachments, forms, syllabi and fee schedules here.

Paths referenced from `content/notices.ts` resolve to this directory, so a
notice with `file: '/documents/exam-form.pdf'` expects `exam-form.pdf` here.

Two rules worth keeping:

1. **Keep one current version of each document.** The previous site still
   linked admission forms dated 2014 and 2015 alongside each other, which is
   how applicants end up submitting a superseded form.

2. **Publish the content as HTML too, where practical.** A fee structure or
   time table that exists only as a scanned PDF is close to invisible to search
   and unreadable on a phone. Put the table in `content/pages.ts` and offer the
   PDF as a download beside it.
